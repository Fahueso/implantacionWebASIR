# 1. Sintaxis de PHP y estructuras de control

Realiza un programa que imprima la tabla de multiplicar de un número, que PHP calculará de manera aleatoria entre 1 y 20.

## Snippet de ayuda

```php
$n = rand(1,20); // número aleatorio entre 1 y 20
echo "Número generado: $n<br>";
```

## Ejemplo de salida para n=7

```php
Número generado: 7
Es impar

Tabla de multiplicar:
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

# 3. Sintaxis de PHP y estructuras de control

Realiza un programa que genere números aleatorios entre 1 y 100, hasta encontrar un múltimplo de 10. Mostrar todos los intentos y el número total de intentos realizados.

## Ejemplo de salida para n=5, 75, 46 y 20
```php
Prueba 1 con el número 5
El número 5 no es múltiplo de 10
Prueba 2 con el número 75
El número 75 no es múltiplo de 10
Prueba 3 con el número 46
El número 46 no es múltiplo de 10
Prueba 4 con el número 20
El número 20 sí es múltiplo de 20.
Hemos necesitado 4 intentos hasta encontrar el número 20.
```
